📱 如何放到 iPhone 桌面？

  1. 将本文件命名为 index.html 上传到你的 GitHub 仓库，并在仓库 Settings → Pages 开启 GitHub Pages。
  2. 用 iPhone 自带的 Safari 浏览器打开生成的网址。
  3. 点击屏幕底部中间的 分享按钮（方框带向上箭头 ⬆️）。
  4. 向下滑动菜单，点击 「添加到主屏幕 (ホーム画面に追加)」。
  5. 桌面上就会出现专属的 「三语乐园」 图标，点开就像原生 App 一样全屏运行！
